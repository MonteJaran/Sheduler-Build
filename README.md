# Scheduler Desktop: downloads

Installers for **Scheduler Desktop**, the offline timetable generator for universities and schools.
This repository only hosts the installers; it contains no source code.

**Download:** [latest release](../../releases/latest) → `Scheduler-Setup-latest.exe` (Windows 10/11, 64-bit).

- Run the installer. If Windows SmartScreen warns about an unrecognised app, choose *More info → Run anyway* (the installer is not code-signed yet).
- The app runs fully offline and updates itself.
- Pricing, the calculator and sign-up: https://scheduler-institution.web.app/pricing
- Support: solutions@radoman.dev
